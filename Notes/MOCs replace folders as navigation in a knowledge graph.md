## Review Question
Why is a MOC fundamentally better than a folder for navigating a large knowledge base?

> [!abstract] Essence (Answer)
> A folder is a rigid hierarchy — each note lives in one place. A MOC is a soft map — one note can appear in multiple MOCs without duplication. As the base grows to thousands of notes, only MOCs keep navigation tractable.
